## About

**MyRoom** is a web version of my room, in this you can interact with objects, know abot me. And this pure made on ```HTML``` & ```CSS```.

Check it out: **https://shivaroom.vercel.app**

## Features

1. You can hover on any object and everythings get blurred, except hovered objects. I chose blur because when we focus on any objects, then everythigs get blurred, same principle I apply here. 

2. When you hover on the Laptop, then if you click then you will be redirect to a new page, which is ```Aboutme.html``` where you can know about me.

3. I also add a Coke because it is important while making any projects.

## Details

It is a very simple and easy to make, first we need some .svg images for our objects, I prefer .svg because we can zoom it more than enough, without the image looks blurred and pixelated.

### Making it yourself

1. Use any AI tools to generate images or if you know to make vector images then you can make it. 
2. If you use AI then make it in .svg with any free tools. 
3. Import it in your projects directory, and build your new Room.
4. Add your .svg images in your page., using ```HTML```
5. Style with ```CSS```
6. And then make a final project.

## How do I get idea?

I was completely bored by portfolio websites, because if you make it simple, then for people it is not worth it. For this reason, you have to make a flashy one with a ton of animation, which people with low-end mobiles are not able to open. Because of this reason, I chose to make a unique one. I just duplicated my room into a web-playable website. Now you can interact with my room—just hover on any object, like when our eyes focus on anything then everything gets blurred, the same principle I applied here. And yeah, this is the brief of my project. And also, when you click on the laptop, then you will transfer to my about me page, where you can know a lot of stuff.
